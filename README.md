## Repository contents

•⁠  ⁠⁠ Powerbiproject.zip ⁠ — compressed project archive.

## Getting started

1.⁠ ⁠Download or clone this repository.
2.⁠ ⁠Extract ⁠ Powerbiproject.zip ⁠.
3.⁠ ⁠Open the included Power BI report file, if present, with [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
4.⁠ ⁠If prompted, configure the data source and refresh the report.
